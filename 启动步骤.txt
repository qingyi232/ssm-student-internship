================================================================================
  学生实习管理系统 — 
  （使用 IntelliJ IDEA + Tomcat，按顺序操作）
================================================================================
：
  · JDK 8（即 Java 1.8）
  · MySQL 5.7 或 8.0
  · IntelliJ IDEA
  · Apache Tomcat 9

================================================================================
一、启动前检查清单（每次开机后建议快速确认）
================================================================================

  □ MySQL 服务已启动
      方法：按 Win+R，输入 services.msc，找到 MySQL 相关服务（如 MySQL57、MySQL80），
            状态为「正在运行」。

  □ 数据库已导入
      本系统使用数据库名：internship_db
      若不确定是否已导入，可用 MySQL Workbench 连接后查看左侧是否有 internship_db。

  □ 项目文件夹完整
      解压后的项目根目录下应包含：pom.xml、src 文件夹、sql 文件夹等。

  □ JDK 为 8（不是 11、17、22）
      打开 cmd，输入：java -version
      应显示 1.8.x 或 openjdk version "1.8.0_xxx"。


================================================================================
二、第一次使用：数据库与配置文件（仅需做一次，或改密码后重做）
================================================================================

【2.1 导入数据库】

  若尚未导入，请执行项目中的脚本：

    项目根目录\sql\internship_db.sql

  可用 MySQL Workbench：打开该文件 → 执行全部语句。
  执行成功后，应存在数据库 internship_db，且有多张表（如 sys_user、student 等）。

【2.2 修改数据库连接密码】

  用记事本或 IDEA 打开：

    src\main\resources\db.properties

  请根据您本机 MySQL 的 root 密码修改（示例）：

    jdbc.driver=com.mysql.cj.jdbc.Driver
    jdbc.url=jdbc:mysql://localhost:3306/internship_db?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf-8&allowPublicKeyRetrieval=true
    jdbc.username=root
    jdbc.password=这里改成您的MySQL密码
    （以下连接池参数一般不用改）

  重要：
    · 密码必须与 MySQL Workbench 里 root 登录密码一致。
    · 若 MySQL 端口不是 3306，请把 jdbc.url 中的 3306 改为实际端口。

【2.3 修改后务必重新编译】

  修改 db.properties 后，建议在 IDEA 中：
    菜单「构建」→「重新构建项目」
  或 Maven 面板：先双击 clean，再双击 compile 或 package。
  然后重启 Tomcat（见下文），否则可能仍使用旧的密码配置。


================================================================================
三、用 IntelliJ IDEA 打开项目
================================================================================

  1. 启动 IDEA。

  2. 「文件」→「打开」，选择项目根目录（包含 pom.xml 的文件夹）。

  3. 若提示信任项目，选择信任。

  4. 等待右下角 Maven 依赖下载完成（首次可能较慢，请耐心等待）。

  5. 确认 JDK 为 8：
     「文件」→「项目结构」（或 Ctrl+Alt+Shift+S）
     →「项目」→「SDK」选择 1.8
     →「语言级别」选择 8
     →「模块」中语言级别也选 8。


================================================================================
四、配置 Tomcat（第一次配置好后，以后一般不用改）
================================================================================

【4.1 准备 Tomcat】

  · 从官网或国内镜像下载 Tomcat 9 的 Windows 64 位 zip，解压到例如：
      D:\apache-tomcat-9.0.116
  · 路径中尽量不要有中文。
  · 解压后该文件夹内应有 bin、conf、lib 等子文件夹。

【4.2 在 IDEA 中添加运行配置】

  1. 菜单「运行」→「编辑配置…」

  2. 左上角点击「+」，选择「Tomcat 服务器」→「本地」。
     （不要选 TomEE 服务器。）

  3. 「服务器」选项卡：
     · 「应用程序服务器」旁点击「配置…」
     · 「Tomcat 主目录」选择您解压的 Tomcat 根目录（内部包含 bin、lib 的那一层）
     · 确定后，应显示 Tomcat 9.0.x，且版本不为「未知」

  4. 「部署」选项卡：
     · 点击「+」→「工件…」
     · 选择：student-internship-system:war exploded
     · 「应用程序上下文」填写：/internship-system
     （注意前面有斜杠）

  5. 「服务器」选项卡中的「HTTP 端口」默认为 8080。
     若 8080 已被其他软件占用，可改为 8081、9090 等，浏览器访问时端口要一致。

  6. 配置名称可将「未命名」改为例如「实习系统-Tomcat」，便于识别。

  7. 点击「确定」保存。


================================================================================
五、日常启动项目（以后每次开机想运行系统时）
================================================================================

  步骤 A：确认 MySQL 服务已启动（见第一节）。

  步骤 B：打开 IDEA，打开本项目。

  步骤 C：等待 Maven/索引就绪（无长时间卡在「正在导入」即可）。

  步骤 D：右上角运行配置下拉框，选择已配置好的「Tomcat」相关项。

  步骤 E：点击绿色三角形「运行」按钮，启动 Tomcat。

  步骤 F：等待下方「运行」窗口出现类似「Artifact is deployed successfully」或
          「Server startup in xxx ms」等表示启动成功的日志。

  步骤 G：打开浏览器（推荐 Edge 或 Chrome），地址栏输入：

          http://localhost:8080/internship-system/

          若您在步骤 5 中把端口改成了 8081，则改为：

          http://localhost:8081/internship-system/

  步骤 H：应出现登录页面。使用测试账号登录（见第七节）。

八、常见问题排查
================================================================================

【问题 1】浏览器提示无法连接、拒绝连接（ERR_CONNECTION_REFUSED）

  原因：Tomcat 未启动，或端口写错。
  处理：
    · 确认 IDEA 里已点击运行且控制台无红色致命错误。
    · 确认浏览器地址中的端口号与「编辑配置 → 服务器 → HTTP 端口」一致。

【问题 2】页面 404

  原因：上下文路径不对。
  处理：使用 http://localhost:端口/internship-system/ （注意 internship-system 与配置中一致）

【问题 3】登录或打开页面时出现 500，提示 Access denied for user 'root'

  原因：db.properties 中的密码与 MySQL 实际密码不一致。
  处理：
    · 修改 src\main\resources\db.properties 中的 jdbc.password。
    · 「重新构建项目」后，重启 Tomcat。

【问题 4】提示 Can't find catalina.jar 或 Tomcat 版本未知

  原因：Tomcat 路径选错，或路径含中文导致异常。
  处理：
    · 重新在「编辑配置 → 应用程序服务器 → 配置」中选择 Tomcat 根目录。
    · 确保该目录下有 lib\catalina.jar。
    · 尽量将 Tomcat 放在 D:\apache-tomcat-9.0.xxx 这类无中文路径。

【问题 5】8080 端口打开的是别的网站

  原因：本机 8080 已被其他程序占用。
  处理：在 Tomcat 运行配置中将 HTTP 端口改为 8081（或其他空闲端口），
        浏览器使用新端口访问。

【问题 6】修改了 JSP 页面想立即看效果

  一般刷新浏览器即可；若修改了 Java 代码或配置文件，需重新编译并重启 Tomcat。


================================================================================
九、一键核对表（启动失败时从上到下检查）
================================================================================

  □ java -version 是否为 1.8
  □ MySQL 服务是否运行
  □ internship_db 是否存在且已导入数据
  □ db.properties 中用户名、密码、端口是否正确
  □ 修改 db.properties 后是否已重新构建并重启 Tomcat
  □ Tomcat 运行配置中是否已部署 war exploded，上下文是否为 /internship-system
  □ 浏览器 URL 端口与配置是否一致
