一、项目概述
================================================================================

【系统名称】学生实习管理系统
【技术框架】SSM（Spring + Spring MVC + MyBatis）
【项目类型】Java Web 应用（WAR 包部署）
【适用场景】高校学生实习全流程管理，包含管理员、指导教师、学生三种角色

【系统核心功能】
  - 多角色登录认证与权限控制
  - 学生信息管理（增删改查、分页、条件搜索）
  - 教师信息管理（增删改查、分页、条件搜索）
  - 实习单位管理（增删改查、分页、条件搜索）
  - 实习记录管理（增删改查、审核、状态流转）
  - 实习任务管理（教师布置、学生更新状态）
  - 实习报告管理（学生提交、支持附件上传、教师审核打分）
  - 实习日志管理（学生记录每日实习情况）
  - 系统公告管理（管理员发布，全角色可查看）
  - 数据统计与可视化（Chart.js 图表）
  - 密码修改

二、技术架构说明
================================================================================

  本系统采用经典的 SSM 三层架构 + MVC 设计模式：

  ┌──────────────────────────────────────────────────────────┐
  │                     浏览器（客户端）                      │
  │   JSP页面 + jQuery + Chart.js + Font Awesome + CSS       │
  └────────────────────────┬─────────────────────────────────┘
                           │ HTTP请求
  ┌────────────────────────▼─────────────────────────────────┐
  │               Spring MVC（前端控制器层）                   │
  │   DispatcherServlet → Controller → ViewResolver → JSP    │
  │   LoginInterceptor（登录拦截）                            │
  ├──────────────────────────────────────────────────────────┤
  │               Spring（业务逻辑层）                        │
  │   Service接口 → ServiceImpl实现类                         │
  │   @Transactional 事务管理                                 │
  ├──────────────────────────────────────────────────────────┤
  │               MyBatis（数据访问层）                        │
  │   Mapper接口 → Mapper.xml（SQL映射）                      │
  │   PageHelper 分页插件                                     │
  ├──────────────────────────────────────────────────────────┤
  │               MySQL 数据库                                │
  │   Druid 连接池管理                                        │
  └──────────────────────────────────────────────────────────┘

  【架构特点】
  1. 前后端不分离：使用 JSP 作为视图层，Controller 返回视图名由 ViewResolver 渲染
  2. 三层分离：Controller → Service → Mapper，职责清晰
  3. 声明式事务：通过 @Transactional 注解管理数据库事务
  4. 统一拦截：LoginInterceptor 拦截所有请求，未登录自动重定向到登录页
  5. 分页封装：PageHelper 插件实现物理分页，前端展示分页导航

四、数据库设计说明
================================================================================

  数据库名称：internship_db
  字符集：utf8mb4
  共 9 张数据表：

  ┌─────────────────────┬──────────────────────────────────────┐
  │ 表名                │ 说明                                 │
  ├─────────────────────┼──────────────────────────────────────┤
  │ sys_user            │ 系统用户表（统一认证，存储所有角色）  │
  │ student             │ 学生信息表（关联 sys_user）           │
  │ teacher             │ 教师信息表（关联 sys_user）           │
  │ company             │ 实习单位表                           │
  │ internship          │ 实习记录表（核心表，关联学生/单位/教师）│
  │ internship_task     │ 实习任务表（关联 internship）         │
  │ internship_report   │ 实习报告表（关联 internship + student）│
  │ internship_log      │ 实习日志表（关联 internship + student）│
  │ announcement        │ 系统公告表                           │
  └─────────────────────┴──────────────────────────────────────┘

  【表关系图】

    sys_user (1) ←──── (1) student      用户-学生 一对一
    sys_user (1) ←──── (1) teacher      用户-教师 一对一
    student  (1) ←──── (N) internship   一个学生可有多个实习记录
    company  (1) ←──── (N) internship   一个企业可有多个实习记录
    teacher  (1) ←──── (N) internship   一个教师可指导多个实习
    internship (1) ←── (N) internship_task     一个实习可有多个任务
    internship (1) ←── (N) internship_report   一个实习可有多个报告
    internship (1) ←── (N) internship_log      一个实习可有多个日志
    sys_user (1) ←──── (N) announcement        一个用户可发多个公告

  【各表字段详解】

  ---- sys_user（系统用户表） ----
    id          INT 主键自增     用户ID
    username    VARCHAR(50)      用户名（唯一，用于登录）
    password    VARCHAR(64)      密码（MD5加密后存储）
    real_name   VARCHAR(50)      真实姓名
    role        INT              角色：1=管理员, 2=教师, 3=学生
    phone       VARCHAR(20)      联系电话
    email       VARCHAR(100)     邮箱
    status      INT              状态：0=禁用, 1=启用
    create_time DATETIME         创建时间
    update_time DATETIME         更新时间

  ---- student（学生信息表） ----
    id          INT 主键自增     学生ID
    user_id     INT 外键         关联 sys_user.id（级联删除）
    student_no  VARCHAR(30)      学号（唯一）
    name        VARCHAR(50)      姓名
    gender      VARCHAR(4)       性别
    age         INT              年龄
    class_name  VARCHAR(50)      班级
    major       VARCHAR(100)     专业
    college     VARCHAR(100)     学院
    phone       VARCHAR(20)      联系电话
    email       VARCHAR(100)     邮箱
    address     VARCHAR(255)     家庭住址
    create_time DATETIME         创建时间
    update_time DATETIME         更新时间

  ---- teacher（教师信息表） ----
    id          INT 主键自增     教师ID
    user_id     INT 外键         关联 sys_user.id（级联删除）
    teacher_no  VARCHAR(30)      工号（唯一）
    name        VARCHAR(50)      姓名
    gender      VARCHAR(4)       性别
    title       VARCHAR(50)      职称
    college     VARCHAR(100)     所属学院
    phone       VARCHAR(20)      联系电话
    email       VARCHAR(100)     邮箱
    create_time DATETIME         创建时间
    update_time DATETIME         更新时间

  ---- company（实习单位表） ----
    id             INT 主键自增  单位ID
    name           VARCHAR(200)  单位名称
    contact_person VARCHAR(50)   联系人
    contact_phone  VARCHAR(20)   联系电话
    address        VARCHAR(255)  单位地址
    description    TEXT          单位简介
    status         INT           状态：0=停用, 1=启用
    create_time    DATETIME      创建时间
    update_time    DATETIME      更新时间

  ---- internship（实习记录表，系统核心表） ----
    id          INT 主键自增     实习ID
    student_id  INT 外键         关联 student.id（级联删除）
    company_id  INT 外键         关联 company.id
    teacher_id  INT 外键         关联 teacher.id（指导教师）
    position    VARCHAR(100)     实习岗位
    start_date  DATE             开始日期
    end_date    DATE             结束日期
    status      INT              状态：0=待审核, 1=进行中, 2=已完成, 3=已取消
    remark      TEXT             备注
    create_time DATETIME         创建时间
    update_time DATETIME         更新时间

  ---- internship_task（实习任务表） ----
    id            INT 主键自增   任务ID
    internship_id INT 外键       关联 internship.id（级联删除）
    title         VARCHAR(200)   任务标题
    content       TEXT           任务内容
    deadline      DATE           截止日期
    status        INT            状态：0=未开始, 1=进行中, 2=已完成
    create_time   DATETIME       创建时间
    update_time   DATETIME       更新时间

  ---- internship_report（实习报告表） ----
    id            INT 主键自增   报告ID
    internship_id INT 外键       关联 internship.id（级联删除）
    student_id    INT 外键       关联 student.id（级联删除）
    title         VARCHAR(200)   报告标题
    content       TEXT           报告内容
    file_path     VARCHAR(500)   附件路径
    status        INT            状态：0=待审核, 1=已通过, 2=已退回
    feedback      TEXT           审核反馈
    score         INT            评分
    submit_time   DATETIME       提交时间
    review_time   DATETIME       审核时间
    create_time   DATETIME       创建时间

  ---- internship_log（实习日志表） ----
    id            INT 主键自增   日志ID
    internship_id INT 外键       关联 internship.id（级联删除）
    student_id    INT 外键       关联 student.id（级联删除）
    title         VARCHAR(200)   日志标题
    content       TEXT           日志内容

  ---- announcement（系统公告表） ----

    title        VARCHAR(200)    公告标题

    create_time  DATETIME        创建时间
    update_time  DATETIME        更新时间

五、后端代码详解 — Entity 实体层
================================================================================

  包路径：com.internship.entity
  共 9 个实体类，与数据库 9 张表一一对应。

  【设计规范】
  - 所有实体类都是标准的 JavaBean：私有字段 + getter/setter + 无参构造器
  - 字段名采用驼峰命名（如 studentId），数据库列名采用下划线命名（如 student_id）
  - MyBatis 通过 mapUnderscoreToCamelCase=true 配置实现自动映射
  - 日期类型字段使用 java.util.Date，并通过 @DateTimeFormat 注解指定表单提交格式

  【特殊设计 — 关联查询冗余字段】

  Internship.java 中除了基本字段外，还有额外的冗余字段：
    - studentName（学生姓名）
    - companyName（企业名称）
    - teacherName（教师姓名）
    - studentNo（学号）
    - gender、className、major、phone

  这些字段不对应数据库列，而是通过 MyBatis 的 LEFT JOIN 查询填充。
  这样做的好处是：一次查询即可获取实习记录及其关联信息，无需多次查询。

  InternshipTask.java 中有冗余字段：
    - internshipLabel（实习标签，格式："学生姓名 - 企业名称"）
  这个字段在 Controller 层手动拼接赋值，用于前端列表展示。

  【关键实体说明】

  User.java — 系统用户
    核心字段：username（登录名）、password（MD5密文）、role（角色码）、status（启禁状态）
    role 值：1=管理员, 2=教师, 3=学生
    登录认证时，系统根据 role 值决定跳转到哪个控制台

  Student.java / Teacher.java — 角色扩展信息
    通过 user_id 字段与 sys_user 表建立一对一关联
    存储角色的专属信息（学号、专业、职称等）

  InternshipReport.java — 实习报告
    支持文件上传，file_path 存储上传文件的服务器路径
    status 状态流转：0(待审核) → 1(已通过) 或 2(已退回)
    教师审核时填写 feedback（反馈）和 score（评分）

六、后端代码详解 — Mapper 数据访问层
================================================================================

  包路径：com.internship.mapper（Java 接口）
  XML路径：src/main/resources/mapper/（SQL 映射文件）

  每个 Mapper 接口对应一个 XML 文件，共 9 对。

  【Mapper 接口与 XML 的对应关系】
    UserMapper.java         ↔  mapper/UserMapper.xml
    StudentMapper.java      ↔  mapper/StudentMapper.xml
    TeacherMapper.java      ↔  mapper/TeacherMapper.xml
    CompanyMapper.java      ↔  mapper/CompanyMapper.xml
    InternshipMapper.java   ↔  mapper/InternshipMapper.xml
    InternshipTaskMapper.java   ↔  mapper/InternshipTaskMapper.xml
    InternshipReportMapper.java ↔  mapper/InternshipReportMapper.xml
    InternshipLogMapper.java    ↔  mapper/InternshipLogMapper.xml
    AnnouncementMapper.java     ↔  mapper/AnnouncementMapper.xml

  【通用方法命名规范】
    findById(Integer id)          — 根据ID查单条记录
    findAll()                     — 查全部记录
    findByCondition(...)          — 条件查询（配合 PageHelper 分页）
    insert(Entity entity)         — 新增
    update(Entity entity)         — 更新
    deleteById(Integer id)        — 删除
    count()                       — 统计总数

  【核心 Mapper 说明】

  InternshipMapper.xml — 实习记录映射（最复杂的 Mapper）
    - 定义了 BaseResultMap 结果映射，将联表查询的列映射到 Internship 实体的冗余字段
    - 使用 SQL 片段 <sql id="Base_Column_List"> 抽取公共列列表
    - 使用 SQL 片段 <sql id="Internship_Join"> 抽取公共的 LEFT JOIN 语句
    - findByCondition 使用 MyBatis 动态 SQL（<where>、<if>）实现条件查询
    - update 使用 <set>、<if> 实现按需更新（只更新非 null 字段）

  UserMapper.xml — 用户映射
    - findByUsername 方法：登录时根据用户名查找用户
    - updatePassword 方法：只更新密码字段

  StudentMapper.xml — 学生映射
    - findByCondition：支持按姓名、学号、专业三个条件模糊查询
    - findByUserId：根据 user_id 查找学生（登录后获取学生信息用）

  【MyBatis 配置说明】
    mybatis-config.xml 中的关键配置：
    - mapUnderscoreToCamelCase=true：下划线转驼峰自动映射
    - lazyLoadingEnabled=true：延迟加载
    - PageHelper 分页插件：拦截 SQL 自动添加分页条件

    1. 用户提交用户名和密码

十、后端代码详解 — 拦截器（interceptor）
================================================================================

  包路径：com.internship.interceptor

  LoginInterceptor.java — 登录拦截器

  【工作原理】
  实现 Spring MVC 的 HandlerInterceptor 接口，重写 preHandle 方法。
  在每个 HTTP 请求到达 Controller 之前执行检查。

  【拦截逻辑】
  1. 从 HttpSession 中获取 loginUser 属性
  2. 如果 loginUser 存在 → 放行（return true）
  3. 如果 loginUser 不存在（未登录）：
     a. 判断是否为 AJAX 请求（检查 X-Requested-With 请求头）
     b. 如果是 AJAX 请求 → 返回 401 状态码 + JSON 错误信息
     c. 如果是普通请求 → 重定向到 /login 登录页面

  【排除路径（不拦截）】
  在 spring-mvc.xml 中配置了排除路径：
    /login       — 登录页面
    /doLogin     — 登录提交
    /logout      — 退出登录
    /static/**   — 静态资源（CSS、JS、图片等）

十五、系统核心业务流程
================================================================================

  ========================================
  流程1：实习全流程
  ========================================

    [管理员] 录入学生 → 录入教师 → 录入实习单位
         ↓
    [管理员] 创建实习记录（分配学生+单位+指导教师）
         ↓ 状态=待审核(0)
    [管理员] 审批实习
         ↓ 状态=进行中(1)
    [教师] 布置实习任务
         ↓
    [学生] 查看任务 → 更新任务状态（进行中/已完成）
    [学生] 撰写实习日志
    [学生] 提交实习报告
         ↓ 状态=待审核(0)
    [教师] 审核报告 → 通过(1)+评分 / 退回(2)+反馈
         ↓
    [管理员] 实习完成后修改状态为"已完成(2)"

  ========================================
  流程2：用户登录流程
  ========================================

    用户输入账号密码 → POST /doLogin
         ↓
    LoginController 调用 UserService.login()
         ↓
    UserService 将密码 MD5 加密后与数据库比对
         ↓ 匹配
    将 User 存入 Session
         ↓
    根据 role 查询对应角色信息存入 Session
         ↓
    重定向到对应角色首页

  ========================================
  流程3：报告提交与审核流程
  ========================================

    [学生] 点击"新增报告" → 填写标题/内容 → 上传附件（可选）→ 提交
         ↓ status=0(待审核)
    [教师] 在报告列表看到待审核报告 → 点击查看详情
         ↓
    [教师] 填写审核反馈和评分 → 选择"通过"或"退回"
         ↓ status=1(通过) 或 status=2(退回)
    [学生] 查看报告详情，看到审核结果和评分
         ↓ 如果退回
    [学生] 修改报告后重新提交

  ========================================
  流程4：新增学生账号流程
  ========================================

    [管理员] 点击"新增学生" → 填写用户名、姓名、学号等信息
         ↓
    AdminController.studentSave() 方法：
    1. 创建 User 对象（role=3, 默认密码=123456 经MD5加密）
    2. 调用 userService.addUser(user) 插入 sys_user 表
    3. 获取新生成的 user.id
    4. 创建 Student 对象，设置 userId = user.id
    5. 调用 studentService.addStudent(student) 插入 student 表
         ↓
    新学生可使用 用户名/123456 登录系统


================================================================================
十六、关键设计决策与说明
================================================================================

  1. 【密码加密】
     使用 MD5 单向加密存储密码。登录时将用户输入的密码做同样的 MD5 运算，
     然后与数据库中存储的密文比对。MD5 是不可逆的，无法从密文还原明文。

  2. 【角色设计】
     采用单用户表（sys_user）+ 角色码（role 字段）的设计。
     不同角色的扩展信息存储在各自的表中（student、teacher），
     通过 user_id 外键关联。这样做的好处是登录认证只需查一张表。

  3. 【分页方案】
     使用 PageHelper 插件实现物理分页（LIMIT 语句），而非内存分页。
     PageHelper 通过 MyBatis 拦截器自动在 SQL 后附加 LIMIT 子句。
     合理配置 reasonable=true，当页码超出范围时自动修正到第一页或最后一页。

  4. 【联表查询】
     Internship 的查询使用 LEFT JOIN 一次性关联 student、company、teacher 表，
     将关联信息直接映射到 Internship 实体的冗余字段中。
     这样前端显示时无需额外查询，减少了数据库访问次数。

  5. 【文件上传】
     使用 Commons FileUpload 组件处理文件上传。
     文件保存在 Tomcat 的 webapp/upload/ 目录下。
     文件名使用时间戳避免重名冲突。
     Spring MVC 配置中限制最大上传大小为 10MB。

  6. 【Session 管理】
     登录成功后，Controller 将三个对象存入 Session：
       loginUser（所有角色共用）
       loginStudent 或 loginTeacher（角色特有）
     Session 超时时间为 30 分钟（web.xml 配置）。
     LoginInterceptor 通过检查 loginUser 是否存在来判断登录状态。

  7. 【前后端交互方式】
     大部分页面采用传统的表单提交 + 页面跳转模式。
     少数功能使用 AJAX（如修改密码、学生更新任务状态），
     Controller 方法返回 Result 对象（JSON 格式）。

  8. 【编码处理】
     web.xml 中配置了 CharacterEncodingFilter，统一使用 UTF-8 编码。
     数据库使用 utf8mb4 字符集，支持中文和表情符号。
     JSP 页面顶部声明 contentType="text/html;charset=UTF-8"。

  9. 【项目构建】
     使用 Maven 管理依赖和构建。
     pom.xml 中指定了所有依赖的精确版本号，确保构建的可重现性。
     打包类型为 WAR，可直接部署到 Servlet 容器（Tomcat）。

  10.【CSS 设计】
     style.css 是一个完整的 UI 设计系统（1800+ 行），包含：
     - CSS 变量定义的主题色系
     - 侧边栏、头部、内容区的布局样式
     - 统计卡片、数据表格、表单、按钮等组件样式
     - 登录页面的双栏布局
     - 分页导航样式
     - 响应式适配
     整体采用翠绿色（#10b981）为主色调，深蓝色（#0f172a）侧边栏，
     风格清新、专业。
